# NSC Tech Hub Static Website

## 📌 Project Overview
This project is the official website for the NSC Tech Hub, a student-led application development agency at North Seattle College. The website showcases the team, services, and projects while providing a professional online presence for the organization.

---

## ⚙️ Tech Stack
- Astro  
- Tailwind CSS  
- Cloudflare Pages  

---

## 🚀 Getting Started

### Prerequisites
Make sure you have the following installed:
- Node.js (LTS version)
- npm (comes with Node)

---

### Installation

git clone https://github.com/NSC-Tech-Hub/nscth-static-website.git
cd nscth-static-website
npm install
