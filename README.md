# NSC Tech Hub Website

## Project Overview
This project is the official website for the NSC Tech Hub, a student-led application development agency at North Seattle College. The website showcases the team, services, and projects.

## Tech Stack
- Astro  
- Tailwind CSS  
- Cloudflare Pages  

## Getting Started

### Installation
```bash
git clone https://github.com/NSC-Tech-Hub/nscth-static-website.git
cd nscth-static-website
npm install
Run Locally
npm run dev
